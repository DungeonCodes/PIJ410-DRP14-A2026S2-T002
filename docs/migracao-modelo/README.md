# Migração para o modelo novo

Use esta pasta para reunir os materiais necessários para atualizar o relatório sem alterar os
modelos originais mantidos em `docs/univesp/`.

## Onde colocar cada arquivo

| Pasta | Conteúdo |
|---|---|
| `referencias/` | Documentos de referência que orientarão a atualização: modelo antigo, instruções, exemplos e observações. |
| `modelo-novo/` | A cópia do modelo novo recebida da UNIVESP. Mantenha-a intacta; ela será a referência de estilos e estrutura. |
| `trabalho/` | Cópia de trabalho criada a partir do modelo novo, com os dados do grupo e o conteúdo migrado. |

## Fluxo

1. Coloque o modelo antigo e os documentos auxiliares em `referencias/`.
2. Coloque o modelo novo em `modelo-novo/`.
3. Não edite os arquivos nas duas pastas acima.
4. A versão editável será criada em `trabalho/`, a partir do modelo novo.
5. O texto-fonte do relatório continua em `docs/relatorio/parcial.md`; a migração para `.docx` deve preservar os estilos do modelo novo.

Não inclua dados pessoais, credenciais ou dados operacionais da instituição parceira.

Os documentos em `referencias/` descrevem materiais usados como insumo e **não representam o
estado funcional atual da aplicação acadêmica**. Para disponibilidade dos módulos, consulte o
[plano de fases](arquitetura/plano-de-fases.md): somente Captação e Matrículas estão ativas; Ads,
Reels orgânicos, Objetivo da Gestão e Arquitetura & Algoritmos permanecem planejados.
